
# Student Grade Tracker

A simple Java console-based application developed as part of the **CodeAlpha Java Programming Internship**.

## Project Overview

The Student Grade Tracker allows users to enter a student's name, subjects, and marks. It calculates the total marks, average marks, highest and lowest marks, and assigns a grade based on the average.

## Features

- Enter student name
- Enter multiple subjects
- Enter marks for each subject
- Marks validation between 0 and 100
- Calculate total marks
- Calculate average marks
- Find highest and lowest marks
- Display the subject with the highest and lowest marks
- Calculate the student's grade
- Display a final student grade report

## Technologies Used

- Java
- Scanner
- Arrays
- Loops
- Conditional Statements

## Grade Criteria

| Average Marks | Grade |
|---|---|
| 90–100 | A |
| 80–89 | B |
| 70–79 | C |
| 60–69 | D |
| 50–59 | E |
| Below 50 | F |

## How to Run

1. Download `StudentGradeTracker.java`.
2. Open it in any Java-supported IDE or online Java compiler.
3. Compile and run the program.
4. Enter the student name, number of subjects, subject names, and marks when prompted.
